# 06-Qwen-Image-Edit-2511

This demo showcases **Alibaba's Qwen-Image-Edit-2511** model via Replicate.com using DelphiFMX for Python.

## Features
- **Smart Semantic Editing:** Modify images while preserving visual style and identity.
- **Text & Object Manipulation:** Add, remove, or modify text and objects with precise control.
- **Identity Preservation:** Keeps facial features and product identities intact across edits.
- **Dynamic API Key:** Input your Replicate API key directly in the GUI.

## Prerequisites
```bash
pip install delphifmx replicate
```

## Running the Demo
1. Open `qwen_image_edit.py`.
2. Enter your Replicate API key.
3. Select a source image, enter an edit prompt (e.g., "change the background to a forest"), and click **Apply Edits**.
