# 01-Nano-Banana-Pro

This demo showcases **Google's Nano Banana Pro** model via Replicate.com using DelphiFMX for Python.

## Features
- **Typography & Reasoning:** Leverages Gemini 3 Pro for accurate text in images.
- **Dynamic API Key:** Input your Replicate API key directly in the GUI.
- **Cross-Platform:** Runs on Windows, macOS, and Linux via DelphiFMX.

## Prerequisites
```bash
pip install delphifmx replicate
```

## Running the Demo
1. Open `nano_banana_pro.py`.
2. Enter your Replicate API key in the password field.
3. Enter a prompt and click **Generate Image**.
