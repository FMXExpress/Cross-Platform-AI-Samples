# 12-Insanely-Fast-Whisper

This demo showcases **OpenAI’s Whisper Large v3** via the **turian/insanely-fast-whisper-with-video** model on Replicate.com using DelphiFMX for Python.

## Features
- **Blazing Speed:** Transcribe hours of audio in seconds.
- **Multimodal Support:** Works with both audio and video files.
- **Translation:** Supports transcribing and translating into English.
- **Dynamic API Key:** Input your Replicate API key directly in the GUI.
- **Cross-Platform:** Runs on Windows, macOS, and Linux via DelphiFMX.

## Prerequisites
```bash
pip install delphifmx replicate
```

## Running the Demo
1. Open `whisper_fast.py`.
2. Enter your Replicate API key.
3. Select an audio or video file.
4. Click **Start Transcription**.
