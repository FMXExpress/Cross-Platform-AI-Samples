# 11-Grok-4

This demo showcases **xAI's Grok 4** reasoning model via Replicate.com using DelphiFMX for Python.

## Features
- **Advanced Reasoning:** Grok 4 is xAI’s most advanced reasoning model, excelling at logical thinking and in-depth analysis.
- **Agentic Logic:** Optimized for complex problem-solving and insightful technical discussions.
- **Dynamic API Key:** Input your Replicate API key directly in the GUI.
- **Cross-Platform:** Runs on Windows, macOS, and Linux via DelphiFMX.

## Prerequisites
```bash
pip install delphifmx replicate
```

## Running the Demo
1. Open `grok_4.py`.
2. Enter your Replicate API key.
3. Enter a complex analytical prompt.
4. Click **Consult Grok 4**.
