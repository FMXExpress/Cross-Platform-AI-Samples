# 03-Gemini-3-Flash

This demo showcases **Google's Gemini 3 Flash** model via Replicate.com using DelphiFMX for Python.

## Features
- **Multimodal Intelligence:** Supports text and image input for complex reasoning.
- **Ultra-Low Latency:** Optimized for fast, interactive AI responses.
- **Image Analysis:** Select a local image and ask Gemini Flash to describe or analyze it.
- **Dynamic API Key:** Input your Replicate API key directly in the GUI.
- **Cross-Platform:** Runs on Windows, macOS, and Linux via DelphiFMX.

## Prerequisites
```bash
pip install delphifmx replicate
```

## Running the Demo
1. Open `gemini_3_flash.py`.
2. Enter your Replicate API key.
3. (Optional) Select an image from your computer.
4. Enter a prompt and click **Run Gemini Flash**.
