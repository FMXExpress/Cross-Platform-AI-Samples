# 10-DeepSeek-R1

This demo showcases **DeepSeek-AI's DeepSeek-R1** reasoning model via Replicate.com using DelphiFMX for Python.

## Features
- **Frontier Reasoning:** Optimized with Reinforcement Learning (RL) for complex logic, math, and coding tasks.
- **Chain of Thought:** Displays the model's reasoning process alongside the final answer.
- **High Performance:** On par with OpenAI's o1 series for abstract reasoning and problem-solving.
- **Dynamic API Key:** Input your Replicate API key directly in the GUI.

## Prerequisites
```bash
pip install delphifmx replicate
```

## Running the Demo
1. Open `deepseek_r1.py`.
2. Enter your Replicate API key.
3. Enter a complex logical problem or math equation.
4. Click **Ask DeepSeek-R1**.
