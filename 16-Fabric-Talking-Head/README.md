# 16-Fabric-Talking-Head

This demo showcases **VEED's Fabric 1.0** image-to-video model via Replicate.com using DelphiFMX for Python.

## Features
- **Portrait Animation:** Specializes in generating "talking head" style videos for influencers and avatars.
- **Audio-Synchronized:** Synchronizes any voice audio file to a static portrait image.
- **Efficiency:** Faster and more cost-effective than general-purpose video models.
- **Dynamic API Key:** Input your Replicate API key directly in the GUI.
- **Cross-Platform:** Runs on Windows, macOS, and Linux via DelphiFMX.

## Prerequisites
```bash
pip install delphifmx replicate
```

## Running the Demo
1. Open `fabric_talking_head.py`.
2. Enter your Replicate API key.
3. Select a portrait **Image** and a voice **Audio** file.
4. Click **Generate Talking Head**.
