# 02-Qwen3-TTS

This demo showcases **Alibaba's Qwen3-TTS** model via Replicate.com using DelphiFMX for Python.

## Features
- **Unified Modes:** Supports **Voice** (presets), **Clone** (3s reference audio), and **Design** (voice description).
- **Multilingual:** High-quality speech across 10+ languages with low latency.
- **Dynamic API Key:** Input your Replicate API key directly in the GUI.
- **Cross-Platform:** Runs on Windows, macOS, and Linux via DelphiFMX.

## Prerequisites
```bash
pip install delphifmx replicate
```

## Running the Demo
1. Open `qwen3_tts.py`.
2. Enter your Replicate API key.
3. Choose a mode (Voice/Clone/Design).
4. Enter text and click **Generate Audio**.
