# 04-Crystal-Video-Upscaler

This demo showcases **philz1337x/crystal-video-upscaler** via Replicate.com using DelphiFMX for Python.

## Features
- **High-Precision Upscaling:** Optimized for portraits, faces, and products.
- **Clarity AI Power:** Uses advanced clarity models for sharp, natural results.
- **GUI Control:** Select local videos and choose upscale factors (2x/4x) directly in the app.
- **Dynamic API Key:** Input your Replicate API key in the GUI.

## Prerequisites
```bash
pip install delphifmx replicate
```

## Running the Demo
1. Open `crystal_video_upscaler.py`.
2. Enter your Replicate API key.
3. Select a source video and click **Start Upscale**.
