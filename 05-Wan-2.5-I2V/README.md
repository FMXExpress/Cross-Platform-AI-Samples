# 05-Wan-2.5-I2V

This demo showcases **Alibaba's Wan 2.5 Image-to-Video** model via Replicate.com using DelphiFMX for Python.

## Features
- **High-Quality I2V:** Generates cinematic videos from static images.
- **Multilingual Support:** Handles complex prompts with high fidelity.
- **One-Pass Sync:** Generates video at 480p, 720p, or 1080p resolutions.
- **Dynamic API Key:** Input your Replicate API key in the GUI.

## Prerequisites
```bash
pip install delphifmx replicate
```

## Running the Demo
1. Open `wan_video_i2v.py`.
2. Enter your Replicate API key.
3. Select a source image, enter a motion prompt, and click **Generate Video**.
